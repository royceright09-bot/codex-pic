# Coospdd W1151 product image assets

400 product JPG images for 50 SKUs, with eight ordered images per SKU.
The first image is the primary image. File bytes and original resolution are preserved.

The image manifest contains only SKU, slot, relative path, byte count, dimensions and SHA-256.
Supplier prices, account information, credentials and local working files are excluded.

Use raw image URLs pinned to the published Git commit. Verify downloaded bytes against manifest.json.
